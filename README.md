# Moritas-Bag
Sitio web responsive para una tienda de bolsos y accesorios llamada Moritas Bags, desarrollado con HTML y CSS como proyecto académico.
# Moritas Bags 👜

Proyecto web desarrollado como parte del curso de Diseño Web.

Este sitio web representa una tienda virtual de bolsos y accesorios, diseñada aplicando principios de diseño responsive, uso de Flexbox, imágenes flexibles y buenas prácticas de maquetación HTML y CSS.

## Contenido
- Página principal (index)
- Página de bolsos
- Página de accesorios

## Tecnologías utilizadas
- HTML5
- CSS3 (Flexbox y diseño responsive)
